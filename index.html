로컬 저장 모드 (Firebase 미연동)

현재는 이 기기 브라우저(localStorage)에만 데이터가 저장됩니다. Firebase를 연동하면 모바일, 태블릿, 다른 PC 어디서든 체크한 내용이 실시간으로 동기화됩니다.

1분 만에 Firebase 무료 연동하는 방법 안내
  1. Firebase Console 접속: console.firebase.google.com에 접속해 구글 로그인합니다.
  2. 새 프로젝트 만들기: '프로젝트 추가'를 누르고 프로젝트 이름을 입력해 생성합니다. (Google 애널리틱스는 해제해도 무방)
  3. 웹 앱 등록: 프로젝트 메인에서 웹 아이콘 </>을 클릭하고 앱을 등록합니다. 화면에 나오는 firebaseConfig = { ... } 코드를 복사합니다.
  4. Firestore 데이터베이스 생성: 왼쪽 메뉴 [빌드] → [Firestore Database] → [데이터베이스 만들기] 클릭 → 테스트 모드에서 시작 선택 → 리전 선택 후 완료.
  5. 설정 붙여넣기: 복사한 설정값을 위의 입력창에 붙여넣고 아래 [연동 및 실시간 동기화 시작] 버튼을 누르면 끝!
